# 🎮 Day 11: Rock, Paper, Scissors

A classic CLI-based Rock, Paper, Scissors game against the computer built using Python.

## 📌 Features
- Implements randomized computer moves using Python's `random` module.
- Normalizes and validates user input using `.strip()` and `.lower()`.
- Evaluates win, lose, and tie outcomes cleanly.

## 🚀 How to Run
```bash
python main.py
```

# ⌛ Day 09:Countdown Timer

A simple terminal-based countdown timer written in Python using standard built-in modules (`time`).

## 📌 Features
- Take user input in seconds.
- Formats time as `MM:SS`.
- Updates countdown in real-time in the terminal.
- Validates user input to prevent runtime errors.

## 🚀 How to Run
```bash
python main.py
```

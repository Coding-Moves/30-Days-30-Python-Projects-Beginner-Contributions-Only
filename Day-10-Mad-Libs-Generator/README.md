# 📝 Day 10: Mad Libs Generator

A fun terminal-based Mad Libs story generator built using Python strings and formatted string literals (f-strings).

## 📌 Features 
- Takes user prompt inputs (adjectives, nouns, verbs).
- Strips trailing whitespaces for clean text formatting.
- Dynamically stitches inputs into a narrative.

## 🚀 How to Run
```bash
python main.py
```
